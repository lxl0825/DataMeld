# DataMeld

DataMeld streamlines real-time data ingestion and processing via event-driven architecture, serving as a centralized orchestrator and analytics dashboard.

With DataMeld, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/DataMeld.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DataMeld is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
